# 端末で遊ぶぷよぷよ

C++ と ncurses で作った、1 人用の落ちものパズルです。端末の盤面に落ちてくる 2 個組のぷよを操作し、同じ色をつなげて消します。

## ビルドと起動

C++11 以降に対応したコンパイラ、ncurses のヘッダーとライブラリ、カラー表示に対応した端末が必要です。リポジトリのディレクトリで次のコマンドを実行します。

```sh
c++ -std=c++11 puyo.cpp -o puyo -lncurses
./puyo
```

## 操作

| キー | 操作 |
| --- | --- |
| ← / → | ぷよの組を左右に 1 マス移動 |
| ↑ | 軸のぷよを中心に時計回りに 90 度回転 |
| ↓ | ぷよの組を 1 マス落とす |
| `q` / `Q` | ゲームを終了 |

## ルール

- 盤面は縦 12 マス、横 6 マスです。赤（`R`）、青（`B`）、緑（`G`）、黄（`Y`）からそれぞれ色が選ばれた 2 個組が盤面上部に現れ、自動で落下します。`.` は空きマスです。
- 2 個組がそれ以上落ちなくなると盤面に固定されます。段差などで浮いているぷよは、空きマスを埋めるように落下します。
- 同じ色のぷよが上下左右につながって 4 個以上になると、そのグループが消えます。消去後に残りのぷよが落下し、新しいグループができれば連鎖します。
- 消えたグループ 1 つにつき 1 点が画面上部の `Score` に加算されます。複数のグループが同時に消えた場合や連鎖で消えた場合も、グループごとに加算されます。
- 次の 2 個組を盤面上部の出現位置に置けなくなると、ゲームが終了します。

## コードの構成

実装は `puyo.cpp` にまとまっています。

| 主なクラス・関数 | 役割 |
| --- | --- |
| `PuyoStuck` | 固定済みの盤面を保持し、重力による落下と同色グループの消去を処理する |
| `PuyoDrop` | 操作中の 2 個組と回転軸を保持し、回転後の候補を作る |
| `PuyoOperator` | 入力、移動・回転時の衝突判定、着地、連鎖、得点を管理する |
| `initScreen` / `display` | ncurses を初期化し、盤面と得点を端末に描画する |
