# 端末で遊ぶぷよぷよ

C++ と ncurses で作った、1 人用の落ちものパズルです。端末の盤面に落ちてくる 2 個組のぷよを操作し、同じ色をつなげて消します。

## ビルドと起動

C++11 以降に対応したコンパイラ、ncurses のヘッダーとライブラリ、カラー表示に対応した端末が必要です。リポジトリのディレクトリでビルドして起動します。

### macOS

```sh
bash build.sh
./build/puyo
```

### Windows（PowerShell）

`g++` が使え、`ncurses` と `unistd.h` を利用できるビルド環境が必要です。

```powershell
.\build.ps1
.\build\puyo.exe
```

## 操作

| 画面 | キー | 操作 |
| --- | --- | --- |
| タイトル | Space | ゲームを始める |
| タイトル | `q` / `Q` | プログラムを終了する |
| プレイ中 | ← / `a` / `A` | ぷよの組を左に 1 マス移動 |
| プレイ中 | → / `d` / `D` | ぷよの組を右に 1 マス移動 |
| プレイ中 | ↑ / `w` / `W` | 軸のぷよを中心に時計回りに 90 度回転 |
| プレイ中 | ↓ / `s` / `S` | ぷよの組を 1 マス落とす |
| プレイ中 | `q` / `Q` | 一時停止する |
| ポーズ | Space | プレイを再開する |
| ポーズ | `q` / `Q` | プレイを終えて結果を表示する |
| ポーズ・結果 | `r` / `R` | 新しいゲームを始める |
| 結果 | Space / `q` / `Q` | タイトルに戻る |

## ルール

- 盤面は縦 12 マス、横 6 マスです。赤（`R`）、青（`B`）、緑（`G`）、黄（`Y`）からそれぞれ色が選ばれた 2 個組が盤面上部に現れ、自動で落下します。`.` は空きマスです。
- 2 個組がそれ以上落ちなくなると盤面に固定されます。段差などで浮いているぷよは、空きマスを埋めるように落下します。
- 同じ色のぷよが上下左右につながって 4 個以上になると、そのグループが消えます。消去後に残りのぷよが落下し、新しいグループができれば連鎖します。
- 消えたグループ 1 つにつき 1 点が画面上部の `Score` に加算されます。複数のグループが同時に消えた場合や連鎖で消えた場合も、グループごとに加算されます。
- 次の 2 個組を盤面上部の出現位置に置けなくなると、結果画面に切り替わります。

## コードの構成

実装は [puyo.cpp](puyo.cpp) にまとまっています。ソースの「処理の概要」の見出しを検索すると、各処理の定義をたどれます。

| 処理の概要 | 主な型・関数 | 役割 |
| --- | --- | --- |
| 座標・移動量・サイズ | `Vec2`、`PosOffset`、`Position`、`Size` | 行と列を使って盤面上の位置や移動量を表す |
| 一次元配列と行列 | `vector`、`matrix` | 盤面のデータを保持し、行と列で要素にアクセスできるようにする |
| ぷよの色・グループ・盤面 | `puyocolor`、`PuyoGroup`、`PuyoStuck`、`PuyoDrop` | ぷよの色、同色のつながり、固定済みの盤面、操作中の 2 個組を表す |
| 端末の初期化と画面描画 | `initScreen`、`drawRectangle`、`displayStart` など | ncurses を初期化し、タイトル・プレイ・ポーズ・結果の各画面を描く |
| プレイの進行と画面遷移 | `PuyoOperator`、`GameController` | ぷよの操作や連鎖、得点を処理し、入力やゲームの状態に応じて画面を切り替える |
| ゲームループとエントリーポイント | `runGame`、`main` | 入力を受け取りながらゲームを更新し、終了時に端末の設定を戻す |
